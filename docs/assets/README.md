# SpatialGL logo

`spatialgl-logo.png` is the generated raster wordmark used by the public README.
The mark depicts multiple light paths meeting a spatial plane. The PNG has a
transparent background. Keep its proportions when displaying it.

Generated with the built-in image generation tool on 2026-10-03, followed by a
color-only refinement for light and dark backgrounds. No third-party logo was
supplied as a reference. The original outputs remain outside the repository;
the selected final asset is copied here.

Constraints: Actual transparent background. No tagline, no other text, no existing company marks, no mockup, no 3D material, no shadows, no watermark.
